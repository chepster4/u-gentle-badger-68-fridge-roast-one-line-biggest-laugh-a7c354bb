# Fridge Roast: One Line, Biggest Laugh

Entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty on [make.fun](https://make.fun/).

`main.ts` (Node 22, standard library only) writes a single one-line roast of a
smart fridge to `/output/entry.txt`:

> I rated my fridge's ice one star in its app. It froze my account.

The joke roasts the fridge itself — its app and its ice maker — with one
word, "froze", doing double duty: the ice is frozen, and the fridge froze the
account in return.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (65 characters, no network access,
no files read).
